TRANSITOPS Fleet Management & Logistics Platform
============================================================

🌐 LIVE DEMO [https://starter-website.ai.studio](https://starter-website.ai.studio)

============================================================ PROJECT
OVERVIEW ============================================================
TransitOps is a full-stack Fleet Management & Logistics Platform built
to manage vehicles, drivers, trips, maintenance, fuel expenses,
analytics, notifications, and role-based administration from a
centralized dashboard.

============================================================ CORE
FEATURES ============================================================ •
Dashboard with KPIs • Vehicle Registry • Driver Management • Trip
Dispatcher • Maintenance & Repairs • Fuel & Expense Tracking • Analytics
& Reports • Notifications • Global Search • CSV/PDF Export • Dark/Light
Theme • Audit Logs • JWT Authentication • Role Based Access Control
(RBAC)

============================================================ MODULES
============================================================

-   Fleet overview

-   Export logs

============================================================ ROLE BASED
ACCESS CONTROL
============================================================

Admin - Full system access

Fleet Manager - Vehicles - Drivers - Trips - Maintenance - Analytics

Safety Officer - Driver Safety - Compliance

Financial Analyst - Finance - Expenses - Reports

Driver - Assigned Trips - Profile

Backend - Node.js - Express.js - MongoDB (Mongoose) - JWT

============================================================ GETTING
STARTED ============================================================ 1.
Install Dependencies npm install

2.  Configure Environment PORT= MONGO_URI= JWT_SECRET=

3.  Seed Database npm run seed

4.  Start Development npm run dev

5.  Production Build npm run build npm run start
